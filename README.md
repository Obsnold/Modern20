# Modern20

A [Foundry Virtual Tabletop](https://foundryvtt.com) game system for the d20
Modern System Reference Document, with the Urban Arcana, d20 Future and d20
Menace Manual material it includes. It is built for Foundry v14.

Every rule and compendium entry is imported from a markdown copy of the SRD
([D20ModernSRD](https://github.com/Obsnold/D20ModernSRD)), so the numbers on the
sheets come from the book's own tables. The tests check them against the
characters and creatures the book prints.

## Installing

In Foundry's **Game Systems** tab, choose **Install System** and paste this
manifest URL:

```
https://github.com/Obsnold/Modern20/releases/latest/download/system.json
```

Foundry then offers each new release as an update.
